🏦 Bank Customer Churn & Retention Analysis 🚀

A comprehensive end-to-end data project focused on predicting customer attrition and enhancing retention strategies. 📈

🎯 Project Overview
This project leverages machine learning to identify the key drivers of customer churn and visualizes actionable insights through an executive-level dashboard.

🛠️ Tech Stack
Python (Scikit-Learn): Machine learning model for churn prediction & driver importance analysis. 🐍

Power BI: Interactive executive dashboard for business decision-making. 📊

Data Engineering: Preprocessing and feature engineering with Pandas. 🧹

🔑 Key Insights
Top Drivers: Total_Trans_Ct and Total_Revolving_Bal are the strongest indicators of attrition. 🔍

Business Impact: High-risk segments identified using Matrix Heatmaps. 🗺️

Retention Strategy: Data-driven recommendations to engage at-risk customers. 🛡️
